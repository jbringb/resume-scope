# ResumeScope web

The Angular frontend for the ResumeScope API. It's a shell for now: layout, navigation, API-key settings and the typed API client. The feature pages are placeholders.

## Stack

- **Angular 22**: standalone components, signals, zoneless change detection and OnPush by default. Forms use Signal Forms.
- **Angular Material 3**, with Roboto and Material Symbols self-hosted from npm.
- **Typed API client** generated by [`@hey-api/openapi-ts`](https://heyapi.dev) from `../src/main/resources/static/openapi.json` into `src/app/api/generated/`.
  - That folder is gitignored and regenerated before every `start`, `build` and `test`.
  - Requests go through Angular's `HttpClient`, so the interceptors apply to them.
- **Tests and tooling:** Vitest through the Angular CLI, ESLint (angular-eslint) and Prettier.

`package.json` `overrides` force `js-yaml` ≥ 4.3 under `@hey-api/json-schema-ref-parser`. It's a build-time-only fix for a CPU denial-of-service advisory in js-yaml 4.2 (quadratic CPU on YAML merge keys). Drop it once that parser ships a newer js-yaml itself (`npm ls js-yaml`).

## Run

```bash
npm ci
npm start            # http://localhost:4200; /api, /health and /openapi.json are proxied to :8086
```

The backend must be running on `:8086`. From the repo root:

```bash
docker compose up -d postgres
OPENAI_API_KEY=sk-... ./gradlew bootRun
```

If the backend has `API_KEY` set, enter that key on the Settings page. It's sent as `X-API-Key` on `/api` calls only, and kept in `sessionStorage`.

## Check

```bash
npm run format:check && npm run lint && npm test -- --watch=false && npm run build
```

CI runs the same steps. `npm run format` fixes formatting.

## How it ships

The root `Dockerfile` builds this app in a Node stage and copies `dist/resume-scope-web/browser/` into Spring Boot's `static/`. The API then serves the app at `/`. `SpaFallbackFilter` returns `index.html` for client-side routes such as `/job-roles/123`, so deep links and reloads work. There's no separate frontend host, and calls stay same-origin, so no CORS setup is needed.
